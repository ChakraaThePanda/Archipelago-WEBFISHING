# Archipelago WEBFISHING

An [Archipelago](https://archipelago.gg) randomizer for **[WEBFISHING](https://store.steampowered.com/app/3146520/WEBFISHING/)**.
Get checks from quests and shop purchases; receive rod/bait upgrades, camp tier unlocks, lures,
consumables, money, and spectral bones from the multiworld.

* See [how randomization works](worlds/webfishing/docs/en_WEBFISHING.md) (goal, what gets
  shuffled, Game Modes, FishSanity).
* Follow the [setup guide](worlds/webfishing/docs/setup_en.md) (full install/connect walkthrough,
  including GDWeave setup) for details.
* Track your goal progress and what you've already fished with [this tracker spreadsheet](https://docs.google.com/spreadsheets/d/1OvY5HNLGyaARQzpzUQ6pmAOxTXj94fuElvfgk4x-d7w/) --
  open it and use **File > Make a copy** to get your own editable copy.

Originally created by [Miyowi](https://github.com/mwoiii), with fishing-quality tweaks
integrated from [Eszenn's Archipelago Tweaks mod](https://github.com/Eszenn/Webfishing-Archipelago-Tweaks).
